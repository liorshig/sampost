Sampost documentation
=====================

Sampost is an xarray-native toolkit for analysing thermodynamic, cloud, and
turbulence fields from System for Atmospheric Modeling (SAM) output. Its
diagnostics preserve Dask laziness until the caller explicitly computes a
result.
